## Exploratory Data Analysis

The Gold layer data was analyzed using Python, Pandas, Matplotlib, and Seaborn to identify sales, product, customer, pricing, and time-based patterns.

### Analysis Performed

- Sales analysis by product category
- Revenue analysis by country
- Top-selling product analysis
- Sales distribution and outlier analysis
- Customer demographic analysis
- Quantity vs sales relationship
- Average selling price analysis
- Monthly sales trend analysis
- Correlation analysis
